# Emergency Response Platform

Real-time emergency response coordination platform connecting:

- Citizens
- Ambulances
- Dispatchers
- Hospitals

## Architecture

Frontend:
React + TypeScript + Vite

Backend:
Node.js + Express + TypeScript

Database:
PostgreSQL + PostGIS

Realtime:
Socket.IO

Cache:
Redis

Maps:
MapmyIndia

Traffic:
MapmyIndia + optional Waze + internal traffic intelligence
